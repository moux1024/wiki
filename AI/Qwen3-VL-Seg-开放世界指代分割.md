## 一、开篇：从"画框"到"描边"的鸿沟

想象一下这样的场景：你对 AI 说"请把图片里那个穿着米色帽子、背着蓝色背包的人分割出来"。现有的多模态大模型（MLLM）能精准地画出一个边界框告诉你"人在这儿"，但当你需要像素级的精确轮廓——比如做图像编辑、机器人抓取、医学影像分析时，那个粗糙的矩形框完全不够用。

这就是 **Open-World Referring Segmentation**（开放世界指代分割）要解决的问题：将不受约束的自然语言描述 grounding 到精确的像素级区域。

过去的方法走两条极端路线：

- **SAM 外挂派**（LISA、GSVA）：MLLM 出框，SAM 出 mask。效果好，但 SAM 带来巨大参数开销和部署复杂度。
- **原生轻量派**（Text4Seg、UFO）：直接在 MLLM 上加轻量分割头，但边界恢复能力差，"切不准"。

**Qwen3-VL-Seg 的核心洞察**：MLLM 预测的边界框不是终点，而是一个语义 grounded 的结构先验。与其把框扔掉再让 SAM 重猜，不如让框全程引导 mask 解码过程。基于此，作者设计了一个仅 **17M 参数**（占基础模型 0.4%）的轻量级 Box-Guided Mask Decoder，在 4B 参数规模上实现了超越 8B 模型的分割精度，且无需任何外部分割模型。

## 二、论文摘要

**论文**: Qwen3-VL-Seg: Unlocking Open-World Referring Segmentation with Vision-Language Grounding
**arXiv**: 2605.07141v1
**机构**: 阿里巴巴通义实验室 (Tongyi Lab)
**发布时间**: 2026年5月8日

开放世界指代分割要求将不受约束的语言表达锚定到精确的像素级区域。现有的多模态大语言模型（MLLM）展现出强大的开放世界视觉定位能力，但其输出仍局限于稀疏的边界框坐标，不足以支持密集视觉预测。

近期基于 MLLM 的分割方法要么直接预测稀疏轮廓坐标（难以重建连续物体边界），要么依赖 Segment Anything Model（SAM）等外部分割基础模型，引入了显著的架构和部署开销。

本文提出 **Qwen3-VL-Seg**，一个参数高效的框架，将 MLLM 预测的边界框视为语义锚定的结构先验，并将其解码为像素级指代分割。其核心是一个轻量级的边界框引导的掩码解码器，结合多尺度空间特征注入、空间-语义查询构建、边界框引导的高分辨率像素融合，以及迭代式掩码感知查询精炼，仅引入 17M 参数（约占基础模型的 0.4%）。

为支持可扩展的开放世界训练，构建了 **SA1B-ORS**——一个衍生自 SA-1B 的数据集，包含两个子集：SA1B-CoRS（类别导向样本）和 SA1B-DeRS（描述性实例级样本）。

为评估模型，策划了 **ORS-Bench**，一个经人工筛选的基准，包含分布内（ID）和分布外（OOD）子集，覆盖多种指代表达类型。大量实验表明，Qwen3-VL-Seg 在封闭集和开放世界设定下均表现强劲，在语言密集型指令上优势显著，且具有强大的分布外泛化能力。通用多模态基准评估进一步表明，模型在面向分割的适配后仍广泛保持了通用多模态能力。

## 三、核心原理：Box 不是终点，而是先验

传统思路把 MLLM 的 box 输出当作"副产品"——模型既然要分割，那 box 就顺手预测一下。但 Qwen3-VL-Seg 反其道而行：**Box 是 MLLM 对"目标在哪里"的最强语义-空间耦合表达**，它同时携带了：

- **语义信息**：box 对应什么类别的物体
- **空间信息**：物体在图像中的位置
- **实例身份**：区分同一类别的不同实例

## 四、架构深潜：四大模块

### 4.1 多尺度空间特征注入（Multi-scale Spatial Feature Injection）

从 MLLM 的中间层提取多尺度视觉特征，注入到分割头中。低层特征捕获精细边界细节，高层特征捕获语义上下文。

### 4.2 空间-语义查询构建（Spatial-Semantic Query Construction）

将 MLLM 输出的边界框坐标转换为可学习的空间-语义查询（query），作为分割头的主干信号。这一步将框的几何信息与 MLLM 的语义理解融合。

### 4.3 Box 引导的高分辨率像素融合（Box-Guided High-Resolution Pixel Fusion）

利用边界框的精确定位来引导高分辨率像素级特征的融合。在框内区域进行精细的像素级特征聚合，框外区域则使用低分辨率特征以节省计算。

### 4.4 迭代 Mask 感知查询精炼（Iterative Mask-Aware Query Refinement）

通过迭代循环逐步精炼分割结果。每次迭代中，上一轮的 mask 预测反馈到查询中，实现 mask 和 query 的互相增强。

## 五、数据引擎：SA1B-ORS 与 ORS-Bench

### 5.1 SA1B-ORS 训练集

从 SA-1B 的 200 万张原始图像中构建两个互补子集：

- **SA1B-CoRS**（Category-Oriented Referring Segmentation）：类别导向样本
- **SA1B-DeRS**（Descriptive Referring Segmentation）：描述性实例级样本

总计 **299 万样本**。

### 5.2 ORS-Bench 评测基准

- **分布内（ID）**：9,055 样本
- **分布外（OOD）**：6 种分布偏移维度

## 六、实验结果

### 封闭集指代分割
Qwen3-VL-Seg-4B 在 6/8 个评测 split 上最佳，**唯一在 4B 规模超越 8B 模型**。

### 开放世界指代分割
7/8 指标最佳，语言密集型场景优势巨大。

### 分布外泛化
全面领先，但风险敏感场景仍有挑战。

### 通用多模态能力保持
Stage 2 恢复了通用能力，表明面向分割的适配不会损害基础 MLLM 能力。

## 七、创新点总结

1. **范式创新**：将边界框从"副产品"重新定义为"语义锚定的结构先验"
2. **架构创新**：17M 参数的 Box-Guided Mask Decoder，SAM-free 设计
3. **数据创新**：SA1B-ORS，299 万样本的大规模训练数据
4. **评测创新**：ORS-Bench，包含 ID 和 OOD 的综合性评测基准
5. **训练创新**：两阶段训练策略（分割特化 → 通用能力恢复）
